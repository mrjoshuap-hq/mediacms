# Plan history archive

Snapshots of MediaCMS Cursor plans. Live plans stay in `~/.cursor/plans/`; this folder is the project archive.

- Browse: [INDEX.md](INDEX.md)
- Machine-readable: [manifest.json](manifest.json)
- Workflow: [`skills/plan-history/SKILL.md`](../../skills/plan-history/SKILL.md)
- Refresh catalog: `python3 skills/plan-history/scripts/refresh_index.py`

Agents must archive new or updated MediaCMS plans here (see `.cursor/rules/plan-history.mdc`).
